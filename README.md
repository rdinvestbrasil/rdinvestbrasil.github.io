# RDI Smart Liquidity — página institucional

Este repositório contém a página institucional estática da RDI.

## Publicar no GitHub Pages

1. Crie um repositório público chamado exatamente `rdinvestbrasil.github.io`.
2. Envie o arquivo `index.html` para a raiz do repositório.
3. Em Settings → Pages, selecione `Deploy from a branch`, branch `main`, pasta `/ (root)`, e salve.
4. Aguarde a publicação. O endereço esperado será `https://rdinvestbrasil.github.io/`.

A publicação pode levar alguns minutos. Não informe o endereço como ativo antes de abrir e confirmar que a página está pública.
